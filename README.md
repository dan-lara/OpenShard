## 📄 About

This project is a reference implementation for a distributed web hosting system that utilizes the idle computing power of volunteers (educational institutions, personal computers, etc.).

Unlike commercial cloud solutions (AWS, Azure) or cryptocurrency-based DePINs, our goal is to provide an accessible and collaborative infrastructure for non-profit projects, reducing reliance on major technological oligopolies.

This repository contains the source code developed as part of the Bachelor's Thesis (TCC) in Computer Engineering at the Federal University of Itajubá (UNIFEI).
